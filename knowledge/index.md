# a2b Global Media client resources

Plain-text copies of our client-facing pages, generated from those pages each time they change, so these files are always current. Fetch only the file you need. Each file starts with its site, type, audience and the link to the web page.

## How to use them

- **Prices** appear only in the Media Packs. Prices differ per site.
- **Welcome Packs** are for existing clients and contain no prices.
- **Example dashboards and example stats reports contain dummy figures** for a made-up client. Never quote them as real results.
- **A client’s contact** is their Partnership Manager or the Content Team.
- **Sites differ.** Use the file for the site you are asked about. Future Transport-News has no magazine.
